Deviation note — the core arc's eight screens. The eight screens under The core arc predate the value sweep and are preserved as drawn, so the board keeps a record of what changed rather than quietly restyling it. Everything from Thread list — the remaining states onward carries the .std class, which is the swept scale: nothing below 14px (typography.md §Accessibility — the 11px product-wide floor does not apply on this surface, and chip labels are text-label 12px by explicit rule), comfortable density from spacing-and-layout.md (24px content padding, 12px stack gap, 16px card padding, 44px minimum tap target, 40px button height), and Lucide icons as inline SVG at a uniform 2px stroke. The core arc still renders body copy at 12.5–13px and timestamps at 10.5px, uses typographic glyphs (‹ ➤ ⬡ ⚙ ⚡) where the swept screens use Lucide symbols, and pads content at 12px rather than 24px — stitch-prompts.md ⚑F1 and ⚑F12 record both as real contradictions between the foundations and the surface files, still awaiting a decision. Take the .std screens as the buildable reference wherever the two disagree. One core-arc defect was corrected rather than preserved: the human-takeover header rendered its escalation reference inside a promise-state chip, which components.md §2 forbids outright (⚑F3), so it now matches every other escalated screen. Avatars use --avatar-bg (neutral-600) on the swept screens rather than the core arc's violet: color.md's hue budget is rationed to promise state and danger, and the assistant's attribution glyph is not either.

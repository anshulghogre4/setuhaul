06 · Admin console — full state gallery

Every screen and state in stitch-prompts.md, in that file's order

Density comfortable throughout (44px rows, 12/16 cell padding, 40px buttons, 24px content padding), light theme default with dark at full parity (U69). Modal states render on a flat rgba(15,23,42,0.5) scrim — dimming, never blurring — with the originating tab named in each caption rather than redrawn twelve times. Icons are Lucide, 2px stroke, inline SVG. No JavaScript: every disclosure is a native <details>, every field a real labelled control, and hover / focus / disabled are shown as static classes.

1 — Console shell (four-tab frame)

Chrome only; the content region is deliberately empty so the shell reads on its own. Two rail destinations (U101 — grounded in what §7.5.7 actually gives this role, not invented icons). Active tab carries two channels, colour and fill. No facility switcher, no facility accent stripe, no top-bar global search, no tab badges — all four excluded per the prompt's own list, and gaps 2–4 in that file's closing table.

Rule types are a fixed registry, so they render as uppercase mono enum tokens — registry values, not prose. Values carry their unit with a space and never a pluralised symbol (60 min, 18,500 kg); times are 24-hour and the effective range uses an en dash. Rows carry no status colour — a rule is not a state, and colour here would dilute promise state and danger. Row 2 hover, row 3 keyboard focus. No per-row toggle, no reorder handle, no simulate affordance: rule changes apply immediately on save; only policy weights are simulated.

8 — Policy tab — weight editor and fairness Danger Zone

Nothing on this tab saves on its own: the whole editor is a staging area and there is deliberately no Save or Apply button and no autosave indicator. Values reach the system only through simulate-then-publish (U27). The priority tiers are read-only with zero interactive affordance — they are the tiers themselves, not tuning coefficients. w_slack shows the focused state. The fairness term is separated into its own panel because the separation is the signal; a note buried in copy would be skimmed past, and a toggle switch is something a cursor can slip onto.
Deviation, stated not silent: the weight inputs render at the shared 40px / 6px-radius .inp metrics, not the 36px / 4px in stitch-prompts.md §8. That 36px came from this file's own Part A and has no source in spacing-and-layout.md, whose comfortable column is 40px control height and a 44px minimum target — the same provenance as the 20px→24px padding fix.

Amber, not red, and the distinction is deliberate: red in this product means danger — expiry, conflict, an action that ends something for another person. 10.A — Simulation — running

A 30-day replay is not instant, so this state carries real weight. The skeleton matches the final layout rather than a centred spinner — a spinner followed by content is a layout jump, and a jump under a cursor is a mis-click. Past roughly ten seconds the status line becomes “Still working — replaying the last 30 days”, because a spinner looks identical at 2 seconds and at 40. Pulse is 1600ms ease-in-out and goes static under prefers-reduced-motion; it is the only looping motion permitted on this surface.
